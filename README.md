# 🏡 Hive

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white) ![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white) ![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black) ![VS Code](https://img.shields.io/badge/VS_Code-0078D4?style=for-the-badge&logo=visual%20studio%20code&logoColor=white)

Uma plataforma interativa de busca de moradias focada em conectar estudantes, proprietários e corretores de forma ágil e personalizada. O **Hive** utiliza uma interface baseada em mapas para entregar a melhor experiência na busca por imóveis, com fluxos de trabalho desenhados especificamente para cada perfil de usuário.

## ✨ Funcionalidades Principais

* **Múltiplos Perfis de Usuário:** Experiências, ferramentas e fluxos customizados para estudantes, proprietários e corretores.
* **Busca por Mapa Interativo:** Navegação fluida para visualização de imóveis disponíveis na região desejada.
* **Map Dark Mode Dedicado:** Opção de visualização em modo escuro exclusiva para o mapa, funcionando de forma totalmente independente do seletor de tema claro/escuro geral do aplicativo.
* **UI/UX Consistente:** Design limpo e moderno com paleta de cores focada em tons de azul, utilizando botões flutuantes (FABs) de layout otimizado para facilitar ações rápidas.

## 🚀 Tecnologias Utilizadas

* **Frontend:** Flutter & Dart
* **Backend & Banco de Dados:** Firebase (Authentication, Cloud Firestore, Storage)
* **IDE:** Visual Studio Code
* **Plataformas:** Android e iOS
